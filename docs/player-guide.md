# 金铲铲麻将玩家指南

> 面向第一次进入游戏的玩家。  
> 本文会随着后续版本持续更新，规则以游戏内实际表现为准。

## 1. 这是一款什么游戏？

《金铲铲麻将》是一款把“麻将胡牌”和“自走棋运营”结合起来的策略小游戏。

你不需要会完整麻将，也不需要玩过自走棋。只要记住一句话：

> 你要用金币买牌、刷新商店、整理手牌，尽量凑出能胡牌的 14 张牌，并用羁绊、海克斯和城邦效果让自己活到最后。

游戏目前有两种模式：

- 单机模式：你和 3 个 AI 对战。
- 联机模式：2-4 名真人玩家进入同一个房间，不足 4 人由 AI 补位。

## 2. 一局游戏的目标

每名玩家都有生命值。每回合结束时，系统会检查每个人的手牌：

- 胡牌的人会获得更好的结算结果。
- 没胡的人会根据距离成型的程度扣血。
- 生命值归零的玩家会被淘汰。
- 最后存活的玩家获胜。

所以你的目标不是每回合都必须立刻胡牌，而是：

1. 让手牌越来越接近胡牌。
2. 用金币和商店提升成型速度。
3. 用羁绊、海克斯、城邦效果减少损失或提高收益。
4. 比其他玩家活得更久。

## 3. 新手第一局怎么玩？

如果你是第一次玩，建议按这个顺序理解：

1. 先看商店里的 5 张牌。
2. 买便宜、能和手牌组成对子或顺子的牌。
3. 手牌太乱时点击“整理”。
4. 金币够时可以刷新商店找关键牌。
5. 有余钱时可以升级，提高高费牌出现概率。
6. 手牌接近 14 张后，观察是否能组成胡牌结构。
7. 点“结束回合”，等待系统结算。

新手最简单的思路：

- 看到相同牌可以买，方便凑对子或刻子。
- 看到连续同花色牌可以买，方便凑顺子。
- 不要一上来把金币全部刷光，保留金币可以吃利息。
- 前几局先学习牌型，不用追求最优数值。

## 5. 牌是什么？

每张牌都有几类信息：

- 牌面：例如 1万、2筒、东风、赤令。
- 花色：万、筒、条、风、令。
- 费用：购买这张牌需要多少金币。
- 稀有度：大致代表牌的费用和强度。
- 羁绊：这张牌属于哪些构筑方向。

目前数牌有三种花色：

- 万
- 筒
- 条

还有特殊牌：

- 风牌：东风、南风、西风、北风
- 令牌：赤令、青令、白令

## 6. 胡牌规则

游戏当前只使用简化麻将规则，不需要记复杂番型。

### 基础胡牌

基础胡牌需要 14 张牌，组成：

> 4 组面子 + 1 组雀头

面子有两种：

- 顺子：同花色连续三张牌。
- 刻子：三张完全相同的牌。

雀头是：

- 两张完全相同的牌。

### 顺子例子

这些是顺子：

- 1万 + 2万 + 3万
- 3筒 + 4筒 + 5筒
- 7条 + 8条 + 9条

这些不是顺子：

- 1万 + 2筒 + 3条，因为花色不同。
- 1万 + 3万 + 5万，因为数字不连续。
- 东风 + 南风 + 西风，因为风牌不组成顺子。

### 刻子例子

这些是刻子：

- 5万 + 5万 + 5万
- 东风 + 东风 + 东风
- 赤令 + 赤令 + 赤令

### 雀头例子

这些是雀头：

- 2筒 + 2筒
- 9条 + 9条
- 白令 + 白令

### 一个基础胡牌例子

下面这 14 张可以胡牌：

- 1万 + 2万 + 3万
- 3万 + 4万 + 5万
- 2筒 + 3筒 + 4筒
- 7条 + 7条 + 7条
- 赤令 + 赤令

拆开看：

- 三组顺子
- 一组刻子
- 一组雀头

所以满足 4 组面子 + 1 组雀头。

## 7. 特殊胡牌

除了基础胡牌，当前版本还支持三种特殊胡牌。

### 七对子

14 张牌刚好组成 7 组对子。

例子：

- 1万 + 1万
- 3万 + 3万
- 2筒 + 2筒
- 5筒 + 5筒
- 4条 + 4条
- 9条 + 9条
- 东风 + 东风

七对子通常比普通胡牌更有奖励。

### 碰碰胡

由 4 组刻子 + 1 组雀头组成。

例子：

- 2万 + 2万 + 2万
- 4筒 + 4筒 + 4筒
- 6条 + 6条 + 6条
- 青令 + 青令 + 青令
- 西风 + 西风

碰碰胡适合经常买相同牌、追刻子的打法。

### 清一色

所有数牌都来自同一种花色。

例子：

- 全部是万牌。
- 全部是筒牌。
- 全部是条牌。

清一色通常需要更专注的构筑方向，但成型后收益更高。

## 8. 商店系统

每回合商店会出现 5 张牌。

你可以：

- 购买牌
- 刷新商店
- 锁定商店
- 整理手牌

### 购买

点击商店里的牌即可购买。

购买后：

- 如果手牌还没满，牌会进入手牌。
- 如果手牌已满，本次购买不会生效，你需要先弃 1 张牌。
- 金币会减少对应费用。

### 刷新

刷新会换一批商店牌。

默认刷新费用是 2 金币。

有些羁绊或海克斯会降低刷新费用。

### 锁定商店

锁定商店可以保留当前商店，不让它被刷新掉。

适合这种情况：

- 你看到关键牌，但现在金币不够。
- 你想下一回合再买。

### 弃牌

点击手牌可以弃掉这张牌。

当前版本每名玩家每回合只能弃 1 张牌。

弃掉的牌会进入弃牌区，同时回到公共牌库，之后其他玩家刷新商店时仍有机会刷到它。

### 整理

整理会按照花色和点数排列手牌。

如果你看不清当前手牌结构，建议先点整理。

## 9. 金币和利息

金币用于：

- 买牌
- 刷新商店
- 升级

每回合结算后，你会获得基础收入。

同时，系统会计算利息：

> 每有 10 金币，获得 1 点利息。

默认利息上限是 5。

例子：

| 当前金币 | 利息 |
| --- | --- |
| 0-9 | 0 |
| 10-19 | 1 |
| 20-29 | 2 |
| 30-39 | 3 |
| 40-49 | 4 |
| 50 及以上 | 5 |

新手建议：

- 不要每回合把钱全部花光。
- 如果局势不紧张，可以存到 10、20、30 金币吃利息。
- 如果快被淘汰了，就要更积极刷新找牌。

## 10. 等级系统

等级会影响商店里不同费用牌出现的概率。

等级越高，越容易刷到高费牌。

当前等级范围是 1 到 6。

### 升级有什么用？

升级后：

- 高费牌更容易出现。
- 更容易找到强力羁绊牌。
- 后期构筑上限更高。

### 什么时候升级？

适合升级的情况：

- 你金币较多。
- 你的低费牌已经差不多成型。
- 你想找 4 费或 5 费关键牌。

不适合升级的情况：

- 你还缺很多低费对子或顺子。
- 你生命值很低，当前更需要刷新找救命牌。
- 你金币不够，升级后没钱买牌。

## 11. 羁绊系统

每张牌除了麻将属性，还有羁绊。

羁绊会根据当前手牌自动统计。

你不需要手动激活，只要手牌里有足够多对应羁绊的牌，效果就会生效。

### 当前羁绊

| 羁绊 | 主要方向 | 新手理解 |
| --- | --- | --- |
| 圣盾城 | 防御 | 接近成型时少扣血 |
| 血刃军 | 伤害 | 刻子越多，胡牌更痛 |
| 小灵族 | 对子 | 鼓励对子和低费构筑 |
| 星穹 | 高费 | 更偏后期和高费牌 |
| 秘术师 | 刷新 | 2 张先省首次刷新，4 张变成每次刷新都省 |
| 迅刃 | 节奏 | 2 张首次刷新便宜，4 张首次刷新免费 |

### 羁绊需要几张牌开启？

羁绊只统计你当前手牌里的牌。

不是每张牌都有羁绊。低费牌通常没有羁绊或只有 1 个羁绊，高费牌才更可能拥有 2 个羁绊。

当前羁绊开启档位如下：

| 羁绊 | 1档 | 2档 | 3档 |
| --- | ---: | ---: | ---: |
| 圣盾城 | 2 张 | 4 张 | 6 张 |
| 血刃军 | 2 张 | 4 张 | 6 张 |
| 小灵族 | 2 张 | 4 张 | 6 张 |
| 星穹 | 2 张 | 4 张 | 6 张 |
| 秘术师 | 2 张 | 4 张 | 暂无 |
| 迅刃 | 2 张 | 4 张 | 暂无 |

简单记法：

- 大多数羁绊是 2 / 4 / 6。
- 秘术师和迅刃目前是 2 / 4。
- 刚凑到 2 张时就能看到这个羁绊开始生效。

### 当前羁绊效果档位

| 羁绊 | 2 张效果 | 4 张效果 | 6 张效果 |
| --- | --- | --- | --- |
| 圣盾城 | 听牌或接近成型时获得基础减伤 | 减伤提高 | 减伤进一步提高 |
| 血刃军 | 刻子构筑胡牌伤害提高 | 伤害提高 | 伤害进一步提高 |

| 迅刃 | 每回合第一次刷新 -1 金币 | 每回合第一次刷新免费 | 暂无 |

### 新手怎么利用羁绊？

如果你不知道买什么，优先考虑：

1. 能组成对子、顺子、刻子的牌。
2. 能让某个羁绊数量变多的牌。
3. 能配合你已选择海克斯的牌。

例子：

- 如果你已经有很多 2、3、6、9 点牌，可以考虑走血刃军。
- 如果你有很多 1、2 点牌和对子，可以考虑小灵族。
- 如果你想频繁刷新，可以留意秘术师和迅刃。

## 12. 海克斯系统

海克斯是局内强化效果。

当前版本会在特定回合出现海克斯三选一。

你只能从三个选项里选一个。

### 当前海克斯

| 海克斯 | 稀有度 | 效果方向 |
| --- | --- | --- |
| 顺水推舟 | 银色 | 顺子候选带来金币收益 |
| 刻不容缓 | 金色 | 刻子胡牌提高伤害 |
| 雀头大师 | 金色 | 接近雀头时减少损失 |
| 花色专精 | 银色 | 更容易出现主要花色牌 |
| 锁血运营 | 金色 | 低血量时减伤 |
| 黄金门票 | 金色 | 刷新相关收益 |
| 快速成型 | 银色 | 更快获得同花色低费牌 |
| 羁绊追踪者 | 银色 | 多羁绊激活后获得奖励 |
| 赌狗狂欢 | 金色 | 刷新更便宜，升级更贵 |
| 稳健运营 | 银色 | 提高利息上限 |
| 天胡之姿 | 棱彩 | 获得高协同牌 |
| 终极听牌 | 棱彩 | 听牌时提高胡牌伤害 |

### 新手怎么选海克斯？

可以按当前局势选择：

- 钱少：选经济类，例如稳健运营、顺水推舟。
- 牌快成型：选伤害类，例如刻不容缓、终极听牌。
- 生命值低：选防御类，例如锁血运营。
- 手牌花色集中：选花色专精。
- 想频繁刷新：选黄金门票、赌狗狂欢。

## 13. 城邦系统

每局开局会随机一个城邦。

城邦是全局规则，会影响整局游戏。

| 城邦 | 效果 |
| --- | --- |
| 黄金港口 | 开局额外金币，利息上限提高 |
| 顺子之城 | 含顺子结构的标准胡牌伤害提高 |
| 刻子矿山 | 商店更偏向刻子构筑牌 |
| 静谧山谷 | 失败扣血降低 |
| 星界集市 | 高费牌出现权重提高 |

### 新手怎么根据城邦调整？

- 黄金港口：可以更早存钱吃利息，也可以更快升级。
- 顺子之城：优先考虑连续同花色牌。
- 刻子矿山：可以多买相同牌，尝试碰碰胡或血刃军。
- 静谧山谷：失败扣血较低，可以更贪经济。
- 星界集市：可以更早考虑升级，找高费牌。

## 14. 回合流程

一回合大致分为：

1. 商店出现牌。
2. 玩家购买、刷新、整理、弃牌、升级。
3. 特定回合选择海克斯。
4. 玩家点击结束回合。
5. AI 自动行动。
6. 系统统一结算。
7. 进入下一回合。

联机模式下，所有真人玩家都结束回合，或者倒计时结束后，才会统一结算。

## 15. 结算规则

每回合结束时，系统会检查每名玩家：

- 是否胡牌。
- 是否接近胡牌。
- 当前有什么胡牌类型。
- 当前有什么羁绊。
- 当前有什么海克斯。
- 城邦是否影响本次结算。

### 胡牌玩家

胡牌玩家会进入胡牌质量对决。

系统会为每名胡牌玩家计算“胡牌战力分”。本回合不是简单地看“谁胡了”，而是看“谁胡得更强”。

> 胡牌战力分 = 基础胡牌分 + 胡牌类型分 + 羁绊加成分 + 海克斯加成分 + 城邦加成分

### 什么牌型最厉害

如果只看胡牌类型，当前版本的优先级是：

> 清一色 > 碰碰胡 > 七对子 > 普通胡

这表示：如果两名玩家胡牌战力分完全相同，会优先判定清一色更强，其次是碰碰胡、七对子，最后是普通胡。

但实际对局中，最终胜负看的是胡牌战力分总和。也就是说，一个带高级羁绊和关键海克斯的七对子，可能打赢一个没有羁绊支持的清一色。

当前版本胡牌战力分如下：

| 项目 | 加分 |
| --- | ---: |
| 基础胡牌 | +10 |
| 普通胡牌型 | +0 |
| 七对子 | +6 |
| 碰碰胡 | +5 |
| 清一色 | +7 |
| 每个已激活羁绊 | +2 |
| 高级羁绊，也就是该羁绊达到更高档位 | 额外 +2 |
| 血刃军刻子加成 | 每个刻子 +1 |
| 顺子之城标准胡 | +4 |
| 相关海克斯命中 | +2 到 +5 |

需要注意：牌型可以叠加。

例如：

- 清一色七对子：会同时获得七对子和清一色的牌型加分。
- 清一色碰碰胡：会同时获得碰碰胡和清一色的牌型加分。
- 普通基础胡：只有基础胡牌分，没有额外牌型分。

所以当前版本理论上最强的方向通常是：

1. 清一色 + 碰碰胡，同时带血刃军刻子加成。
2. 清一色 + 七对子，同时带小灵族、花色专精等配合。
3. 清一色普通胡，但拥有多个高档羁绊和命中海克斯。
4. 单独碰碰胡或七对子。
5. 普通胡。

这不是固定答案。你最终要比的是总分，而不是只看牌型名字。

### 胡牌以后怎么扣血

如果只有 1 名玩家胡牌，他就是本回合胜者。

如果多名玩家同时胡牌，胡牌战力分最高者是本回合胜者。

本回合胜者不扣血。

其他也胡牌但质量较低的玩家，会按分差少量扣血：

> 扣血 = min(5, max(1, 最高胡牌战力分 - 当前玩家胡牌战力分))

也就是说，同样胡牌但输掉质量对决，最低扣 1 血，最高扣 5 血。

如果胡牌战力分相同，会继续比较：

1. 胡牌类型优先级：清一色 > 碰碰胡 > 七对子 > 普通胡。
2. 羁绊档位总和。
3. 手牌费用总和。
4. 剩余金币。
5. 如果仍然完全相同，则并列第一，本回合不互相扣血。

举例：

| 玩家 | 胡牌情况 | 胡牌战力分 | 结果 |
| --- | --- | ---: | --- |
| A | 清一色 + 血刃军 | 25 | 本回合胜者，不扣血 |
| B | 七对子 | 19 | 扣 5 血 |
| C | 普通胡 + 多个羁绊 | 22 | 扣 3 血 |
| D | 碰碰胡 | 20 | 扣 5 血 |

B 和 D 的分差分别是 6 和 5，但胡牌质量落败最多只扣 5 血，所以不会因为“自己也胡了”还被打得太重。

### 未胡牌玩家

未胡牌玩家会扣血。

一般来说：

- 越接近胡牌，扣血越少。
- 越散乱，扣血越多。
- 圣盾城、锁血运营、静谧山谷等效果可以降低损失。

当前版本的基础扣血如下：

| 手牌状态 | 基础扣血 |
| --- | ---: |
| 听牌或非常接近胡牌 | 4 |
| 一向听或比较接近 | 7 |
| 未成型 | 10 |

然后再计算减伤：

- 圣盾城：听牌或接近胡牌时，根据羁绊档位降低失败扣血。
- 锁血运营：生命值低于 35 时，受到伤害降低 30%。
- 静谧山谷：本局所有失败扣血降低 20%。

减伤后的扣血会向上取整。例如本来要扣 7 血，减伤后是 5.6，则实际扣 6 血。

如果一回合没有任何玩家胡牌，所有玩家都会按“未胡牌玩家”的规则结算扣血。

### 最终结算和排名

当你生命值归零时，界面会弹出淘汰结算。整局游戏结束时，所有玩家都会看到最终结算弹窗。

联机模式下，如果你被淘汰但对局还没有结束，可以在淘汰结算弹窗中点击“继续观战”。点击后你会留在房间里，继续查看公共玩家状态、回合进度、战报和最终结算；你不能再购买、刷新、弃牌或结束回合。

最终排名按淘汰顺序计算：

- 最后存活的玩家是第 1 名。
- 越晚被淘汰，名次越高。
- 同一回合被淘汰时，会按本回合表现、淘汰前生命值、受到伤害等信息稳定排序。

联机模式下，每个玩家都会看到同一份最终排名。

## 16. 单机模式说明

单机模式适合熟悉规则。

特点：

- 你和 3 个 AI 对战。
- AI 会自动买牌、刷新、弃牌和参与结算。
- 你可以慢慢看牌，不需要担心其他真人玩家等待。

建议新手先玩单机：

1. 学会基础胡牌。
2. 认识羁绊。
3. 体验金币和刷新节奏。
4. 再进入联机模式。

## 17. 联机模式说明

联机模式支持多人房间。

### 创建房间

1. 首页点击“联机模式”。
2. 输入昵称。
3. 点击“创建房间”。
4. 复制房间号发给朋友。

### 加入房间

1. 首页点击“联机模式”。
2. 输入昵称。
3. 输入朋友给你的房间号。
4. 点击“加入房间”。

### 准备和开始

- 非房主需要点击准备。
- 房主可以点击开始游戏。
- 不足 4 人时，系统会自动补 AI。

### 联机中能看到什么？

所有玩家都能看到：

- 其他玩家生命值、金币、等级。
- 其他玩家是否结束回合。
- 当前城邦和回合。
- 战报和结算。
- 自己被淘汰后的观战画面和最终排名。

只有你自己能看到：

- 自己手牌。
- 自己商店。
- 自己可选海克斯。

这意味着联机中不能直接看到对手手牌。

## 18. 常见新手问题

### 我应该先凑顺子还是刻子？

新手建议先看手牌：

- 连续牌多，就凑顺子。
- 相同牌多，就凑刻子。
- 对子多，就考虑七对子。

同时看城邦和海克斯：

- 顺子之城适合顺子。
- 刻子矿山、血刃军、刻不容缓适合刻子。

### 我什么时候该刷新？

适合刷新：

- 商店没有任何能配合手牌的牌。
- 你已经确定构筑方向，正在找关键牌。
- 你有迅刃、秘术师等刷新折扣。

不适合刷新：

- 金币很少。
- 当前商店已经有能买的牌。
- 你想存钱吃利息。

### 我什么时候该升级？

适合升级：

- 金币比较充足。
- 你想找高费牌。
- 当前低费牌已经够用。

不适合升级：

- 你还没凑出基本牌型。
- 你血量很低，需要立刻刷新找牌。

### 手牌满了怎么办？

当前版本没有备牌区。

如果手牌已经满 14 张，商店购买不会生效。

你需要先弃 1 张牌，再购买新的牌。

如果手牌很乱，先点整理，再决定弃什么。

### 为什么我明明差一点胡牌，还是扣血？

因为当前还没有真正胡牌。

不过接近胡牌通常会比完全散乱扣得少，并且某些羁绊或海克斯可以继续减少损失。

### 为什么联机中我看不到别人的手牌？

这是规则设计。

联机模式只公开公共信息，不公开私有手牌和商店。

### 为什么背景音乐不是一打开页面就播放？

这是浏览器限制。为了避免网页未经允许自动播放声音，BGM 会在你第一次点击或按键后开始循环。

你可以在右上角音效设置里分别调整：

- 操作音效音量。
- BGM 音量。

## 19. 积分和排行榜

当前版本有轻量积分系统。

### 单机积分

单机积分保存在当前浏览器里。

| 排名 | 积分变化 |
| --- | ---: |
| 第 1 名 | +30 |
| 第 2 名 | +10 |
| 第 3 名 | -10 |
| 第 4 名 | -20 |

最低积分是 0，不会扣成负数。

### 联机积分

联机积分由服务端根据最终排名结算，玩家不能自己提交积分。

| 排名 | 基础积分变化 |
| --- | ---: |
| 第 1 名 | +40 |
| 第 2 名 | +20 |
| 第 3 名 | 0 |
| 第 4 名 | -20 |

如果真人玩家不足 4 人，联机积分会按真人数量降低倍率。只有 1 名真人时不计联机积分。

### 段位

积分会映射到段位：

- 青铜雀士
- 白银雀士
- 黄金雀士
- 铂金雀士
- 钻石雀士
- 棋圣雀王

首页可以进入“排行榜”，查看单机榜和联机榜。

需要注意：当前还没有账号系统。浏览器本地身份被清除后，单机积分也会丢失。

## 20. 新手推荐打法

### 打法一：顺子流

适合：

- 同花色连续牌多。
- 城邦是顺子之城。
- 海克斯有顺水推舟或花色专精。

思路：

1. 优先买同花色连续牌。
2. 不要乱买太多不同花色。
3. 争取组成多个顺子。
4. 最后补一个对子做雀头。

### 打法二：刻子流

适合：

- 相同牌多。
- 商店经常刷到重复牌。
- 有血刃军、刻子矿山、刻不容缓。

思路：

1. 优先买相同牌。
2. 凑三张一样形成刻子。
3. 尽量形成碰碰胡。
4. 用血刃军提高胡牌收益。

### 打法三：对子流

适合：

- 起手对子多。
- 小灵族牌多。
- 很多牌都能凑成两张。

思路：

1. 尽量保留对子。
2. 避免过早拆对子。
3. 朝七对子方向发展。

### 打法四：经济运营流

适合：

- 开局金币多。
- 城邦是黄金港口或静谧山谷。
- 海克斯有稳健运营。

思路：

1. 前期少刷新。
2. 尽量存到 10、20、30 金币吃利息。
3. 中后期用经济优势升级和找关键牌。
