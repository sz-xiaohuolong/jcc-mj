# 联机模式说明

## 启动

```bash
npm install
npm run dev
```

前端默认连接 `http://localhost:8787`。如果后端地址不同，可以设置：

```bash
VITE_SERVER_URL=http://localhost:8787 npm run dev:client
```

## 本地双浏览器测试

1. 打开 `http://localhost:5173`。
2. A 浏览器进入“联机模式”，输入昵称，创建房间。
3. 复制房间号。
4. B 浏览器或无痕窗口进入“联机模式”，输入昵称和房间号，加入房间。
5. B 点击准备。
6. A 作为房主点击开始游戏。
7. 服务端自动补足 AI 到 4 人。
8. 两个浏览器会看到同一个城邦、回合、公共玩家状态，但只能看到自己的手牌和商店。

## 当前联机规则

- 采用同步回合制。
- 每名真人玩家同时操作自己的私有商店和手牌。
- 服务端保存权威 `GameState`。
- 客户端只发送操作意图。
- 所有操作通过 ack 返回成功或错误。
- 所有真人玩家结束回合，或服务端倒计时结束后，统一结算。
- AI 由服务端补位并参与结算。

## 重连

- 创建或加入房间后，客户端保存 `sessionToken` 到 `localStorage`。
- 断线后服务端将玩家标记为离线。
- 60 秒内重新连接并发送 token，可以恢复房间和游戏状态。
- 当前版本实现基础恢复，超时后会拒绝重连；AI 托管的长期策略留到后续版本扩展。

## 当前限制

- 房间和游戏状态存于内存，服务重启会丢失。
- 未接入账号、匹配、聊天、观战、排行榜。
- 暂不做多服务器同步。
- AI 托管逻辑较简单。
- UI 已能完成联机操作闭环，但移动端未深度优化。
