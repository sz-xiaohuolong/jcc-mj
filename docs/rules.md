# 羁绊麻将规则

## 麻将胡牌规则

当前版本实现简化麻将胡牌，不做国标复杂番型。

基础胡牌要求：

- 手牌 14 张。
- 4 组面子 + 1 组雀头。
- 面子可以是顺子或刻子。
- 顺子只允许同花色连续三张，例如 3万、4万、5万。
- 刻子是三张相同牌。
- 雀头是两张相同牌。

额外支持：

- 七对子：7 组对子。
- 碰碰胡：4 组刻子 + 1 组雀头，作为胡牌后的加分类型。
- 清一色：全部为同一种数牌花色，作为胡牌后的加分类型。

核心实现位于 `src/engine/huChecker.ts`。

## 羁绊规则

羁绊从当前手牌自动统计。

| 羁绊 | 当前效果 |
| --- | --- |
| 圣盾城 | 听牌或接近成型时减免失败扣血 |
| 血刃军 | 刻子越多，胡牌伤害越高 |
| 小灵族 | 对子构筑方向，后续可扩展收益 |
| 星穹 | 高费牌构筑方向，城邦可提高高费权重 |
| 秘术师 | 刷新折扣 |
| 迅刃 | 每回合首次刷新折扣 |

核心实现位于 `src/engine/traitEngine.ts`。

## 海克斯规则

第 2 / 5 / 8 回合触发海克斯选择。玩家三选一，AI 自动按规则评分选择。

当前包含：

顺水推舟、刻不容缓、雀头大师、花色专精、锁血运营、黄金门票、快速成型、羁绊追踪者、赌狗狂欢、稳健运营、天胡之姿、终极听牌。

第一版中部分海克斯已进入结算和经济计算，部分作为后续扩展标签保留。

## 城邦规则

开局随机一个城邦：

| 城邦 | 效果 |
| --- | --- |
| 黄金港口 | 初始金币增加，利息上限提高 |
| 顺子之城 | 标准胡牌额外伤害 |
| 刻子矿山 | 商店偏向血刃军和刻子构筑 |
| 静谧山谷 | 失败扣血降低 |
| 星界集市 | 高费牌出现权重提高 |

核心实现位于 `src/engine/cityEngine.ts` 与 `src/engine/shopEngine.ts`。

## 结算规则

每回合结束：

1. AI 自动完成购买、刷新和弃牌。
2. 系统检查每名玩家手牌。
3. 已胡牌玩家进入胡牌质量对决。
4. 未胡牌玩家按距离成型程度扣血。
5. 羁绊、海克斯和城邦会修正胡牌战力或扣血。
6. 生命值为 0 的玩家淘汰。
7. 只剩 1 名玩家存活时游戏结束。

多人同时胡牌时，每名胡牌玩家计算胡牌战力分：

```text
胡牌战力分 = 基础胡牌分 + 胡牌类型分 + 羁绊加成分 + 海克斯加成分 + 城邦加成分
```

胡牌战力分最高者获得本回合胜利。其他已胡牌玩家根据分差少量扣血：

```text
扣血 = min(5, max(1, 最高胡牌战力分 - 当前玩家胡牌战力分))
```

如果分数相同，依次比较胡牌类型优先级、羁绊档位总和、手牌费用总和、剩余金币；仍然相同则并列第一，不互相扣血。

弃牌和出售牌会回到公共牌库。当前玩家界面不再提供备牌区；手牌满 14 张时不能继续购买，需要先弃 1 张牌。

核心实现位于 `src/engine/damageEngine.ts` 和 `src/engine/gameEngine.ts`。
